## Meta Open Sound — Meta Steel Guitar

StrumLab can stream the **Meta Steel Guitar** sample set from the `facebookincubator/Meta-open-sound` repository at runtime.

- Project: Meta Open Sound
- Instrument: Meta Steel Guitar
- Sample license: CC0 1.0 Universal
- Source: `systems/instruments/meta-steel-guitar/`

The sample recordings are not copied from Recursive Arts. StrumLab dynamically selects a physical-string/fret recording and one of three velocity layers for each played note. If the network is unavailable before a sample has been cached, StrumLab falls back to its local synthesized pluck engine.

The Meta Open Sound repository also contains code under its own repository license; StrumLab does not copy that implementation code.
